# src/pi

This is the one place in jpi allowed to reach past Pi's public extension API.
Everything here either mirrors a Pi-internal type, monkeypatches a Pi object,
or duplicates behavior Pi keeps unexported. When Pi ships a new version, this
directory is where to check.

## Rules

- `src/pi/` is the only non-test directory allowed to declare Pi-internal
  type mirrors or patch/reach into Pi objects.
- `src/core` may import from `src/pi`. `src/pi` must never import from
  `src/core` — the dependency only runs one way.
- A coupling that can't be moved here yet (it's still entangled with a
  module) gets a marker comment at its call site instead:

  ```
  // pi-internal(<topic>): <one-line why>
  ```

  `<topic>` groups related markers so they can be swept together later. See
  "Markers elsewhere" below for the sites that carry one today.

## Upgrade checklist

On a Pi version bump:

1. `npm install` the new `@earendil-works/*` versions.
2. `vp test tests/pi` — the canary suite. A red canary means the coupling it
   covers has actually changed upstream; go fix the corresponding `src/pi/`
   file (or, for `tests/pi/boundary.test.ts` going red, either the marker
   ledger drifted or a Pi-internal reach-in escaped `src/pi/`/`tests/pi/`).
3. `vp test` — the full suite, to catch anything a canary doesn't cover
   directly (e.g. a module's own unit/e2e tests breaking because a `src/pi/`
   function's behavior shifted underneath it).
4. Review every "Canary" cell marked "marker only" or "partial" above against
   upstream's changelog/source by hand — these have no automated check, so a
   behavior change there won't turn any test red on its own.
5. Update every "Verified against" cell (both tables) to the new version once
   the above is clean, and update the "Where" cells if line numbers or
   surrounding function names in this checklist's own file references moved.
   As of this writing, every row is verified against
   `@earendil-works/pi-coding-agent@0.84.4` /
   `@earendil-works/pi-tui@0.84.4` (bundled) / `@earendil-works/pi-ai@0.84.4`
   (bundled).
